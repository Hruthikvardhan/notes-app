================================================================
PAPER DRAWING TIPS
================================================================

When drawing on paper:

1. Use a ruler for clean boxes
2. Draw outer page boundary first
3. Fill sections top → bottom
4. Use different pen colors:
   - Black pen: layout boxes and text
   - Blue pen: interactive elements (buttons, links)
   - Red pen: error/danger states (delete, trash)
   - Pencil: notes and annotations

5. Mark dimensions roughly:
   - Sidebar: ~264px wide
   - Note card: variable height (masonry), ~260px wide
   - Grid columns: 4 on desktop, 1 on mobile

6. Use these symbols consistently:
   [  ] = button
   {  } = input / textarea
   [av] = avatar circle
   ▤    = masonry card
   📌   = pin icon
   🗑   = delete/trash icon
   ↺    = restore icon
