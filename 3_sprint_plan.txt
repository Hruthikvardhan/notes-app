SPRINT 1 — BACKEND FOUNDATION (MODELS + AUTH API)
Duration : Day 1–2
Goal     : Express server running, MongoDB connected, register
           and login work end-to-end via Postman/curl
================================================================

TASK-001  Initialize Node project + install dependencies   [P1] [ ]
  - npm init, npm install express mongoose dotenv cors
    bcryptjs jsonwebtoken express-validator morgan
    multer cloudinary helmet compression cookie-parser
  - npm install -D nodemon
  Estimated time: 15 min

TASK-002  Create folder structure                          [P1] [ ]
  server/{models,controllers,routes,middleware,services,
          utils,config}
  Estimated time: 5 min

TASK-003  config/database.js + config/cloudinary.js         [P1] [ ]
  - Mongoose connect function with error handling
  - Cloudinary SDK config from env vars
  Estimated time: 15 min

TASK-004  utils/ApiResponse.js + utils/ApiError.js           [P1] [ ]
  - Consistent success/error response shape across all routes
  Estimated time: 10 min

TASK-005  utils/asyncHandler.js                              [P1] [ ]
  - Wraps async controllers so try/catch isn't repeated everywhere
  Estimated time: 10 min

TASK-006  utils/wordCounter.js                               [P2] [ ]
  - stripMarkdown(), getWordCount(), getReadTime() (200 wpm)
  Estimated time: 15 min

TASK-007  models/User.js                                     [P1] [ ]
  - name, email (unique), password (hashed, select:false),
    profilePic, bio, theme, defaultNoteColor, lastLogin,
    isActive, refreshToken
  - pre('save') bcrypt hashing hook
  - comparePassword() and toSafeObject() instance methods
  Estimated time: 30 min

TASK-008  middleware/authMiddleware.js (protect)              [P1] [ ]
  - Verify Bearer access token, attach req.user
  - Handle expired vs invalid token distinctly
  Estimated time: 20 min

TASK-009  middleware/errorHandler.js + notFound               [P1] [ ]
  - Central error handler: Mongoose CastError, duplicate key
    (11000), validation errors → consistent JSON shape
  Estimated time: 20 min

TASK-010  middleware/validate.js (express-validator wrapper)  [P2] [ ]
  Estimated time: 10 min

TASK-011  controllers/authController.js                       [P1] [ ]
  - register, login (issue access + refresh JWT)
  - logout, getMe, updateProfile, changePassword
  - uploadAvatar (Cloudinary), refreshToken
  Estimated time: 60 min

TASK-012  routes/authRoutes.js + server.js wiring              [P1] [ ]
  - Mount /api/auth, helmet, cors, cookie-parser, morgan
  - /api/health route
  Estimated time: 20 min

TASK-013  Manual test via curl/Postman                        [P1] [ ]
  - POST /api/auth/register → 201 + tokens
  - POST /api/auth/login → 200 + tokens
  - GET /api/auth/me with Bearer token → user object
  - POST /api/auth/refresh-token with cookie → new access token
  Estimated time: 20 min

SPRINT 1 DONE WHEN:
  ✓ npm run dev starts server, "MongoDB connected" logs
  ✓ Register/login return access token + set refresh cookie
  ✓ Protected /me route rejects requests with no/expired token
  ✓ Passwords are stored hashed, never returned in responses
